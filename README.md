# Nexo Chat — стартовый проект

Адаптивный веб-мессенджер с дизайном Liquid Glass. В проект включены интерфейс, Supabase Auth, схема базы данных, политики RLS и realtime-подписка на новые сообщения.

## Что реализовано

- Регистрация и вход по email/паролю.
- Профили пользователей.
- Создание групп и каналов.
- Отправка и получение сообщений в реальном времени.
- Поиск чатов, мобильная раскладка и стеклянный интерфейс.
- Row Level Security (RLS) для ограничения доступа к чатам и сообщениям.

## Запуск — настрой один раз

### 1. Создай Supabase-проект
1. Открой https://supabase.com/dashboard и создай проект.
2. В настройках проекта найди Project URL и publishable key (или legacy anon key).
3. Открой `app.js` и вставь значения в первые две строки-константы:
   ```js
   const SUPABASE_URL = "https://YOUR_PROJECT.supabase.co";
   const SUPABASE_ANON_KEY = "YOUR_PUBLISHABLE_OR_ANON_KEY";
   ```
   Эти ключи предназначены для клиента. **Никогда не вставляй `service_role` или secret key в браузерный код.**

### 2. Создай таблицы
1. В Supabase открой SQL Editor.
2. Скопируй весь `supabase_schema.sql` и выполни.
3. В Authentication → URL Configuration добавь адрес сайта в Site URL и Redirect URLs.
4. Для быстрого теста можно отключить подтверждение email в Authentication → Providers → Email. Для публичного запуска лучше оставить подтверждение включённым и настроить SMTP.

### 3. Запусти сайт
Самый простой вариант — загрузить `index.html` и `app.js` на статический хостинг (например, Netlify, Cloudflare Pages или GitHub Pages). Для локального теста запусти любой локальный static server из папки проекта, например:
```bash
python -m http.server 8000
```
Затем открой http://localhost:8000. Не открывай файл напрямую через `file://`.

## Важные ограничения текущего starter-проекта

Это работающий стартовый проект, а не уже опубликованный сервис. Нужны собственный Supabase-проект и хостинг, чтобы люди могли подключаться по интернету.

- Создание группы и канала работает после настройки Supabase.
- Для безопасности приглашение людей по email должно быть оформлено через серверную Edge Function, которая проверяет пользователя и добавляет его в комнату. Не вставляй секретный ключ в браузер.
- Текущая форма личного чата — упрощённая демонстрация и не является полноценной системой приглашений. В текущем UI можно создавать группы/каналы, но безопасный поиск и приглашения по email требуют серверного endpoint.
- Голосовые/видеозвонки, push-уведомления, шифрование end-to-end, модерация, восстановление пароля и отправка файлов не входят в эту версию.
- Перед публичным запуском обязательно проверь RLS-политики в тестовом проекте, добавь rate limits, CAPTCHA/защиту регистрации и политику конфиденциальности. Не используй этот проект для чувствительных переписок без отдельного аудита безопасности.

## Структура
- `index.html` — UI и Liquid Glass стили.
- `app.js` — клиентская логика и Supabase Realtime.
- `supabase_schema.sql` — таблицы, триггер профиля, RLS и Realtime.
- `config.example.js` — пример конфигурации.

## Брендинг
Название и сине-чёрная палитра Nexo Chat вдохновлены предоставленным логотипом. Логотип в интерфейсе сейчас сделан векторной буквой N; заменяй её своим файлом, если хочешь использовать оригинальный знак.
